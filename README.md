# Dot&Craft — интернет-магазин цифровых услуг

Тестовое задание: небольшой интернет-магазин на 3 страницы (Главная, Каталог,
Карточка товара) + рабочая корзина.

**Стек:** React 19 + TypeScript + Vite + Tailwind CSS v4 + React Router v7

---

## Быстрый старт

Требования: Node.js 20+ и npm.

```bash
git clone <ссылка-на-репозиторий>
cd DotCraft
npm install
npm run dev
```

Приложение поднимется на `http://localhost:5173`.

Другие команды:

```bash
npm run build     # сборка для продакшена (tsc -b && vite build) в папку dist/
npm run preview   # локальный просмотр production-сборки
npm run lint      # проверка кода линтером (oxlint)
```

`node_modules` не включён в репозиторий — после клонирования обязателен
`npm install`.

## Что реализовано

### Главная (`/`)

- Header с логотипом, навигацией и корзиной;
- баннер с призывом перейти в каталог;
- блок категорий (карточки-ссылки в отфильтрованный каталог);
- 6 карточек товаров;
- Footer с описанием, ссылками и контактами.

### Каталог (`/catalog`)

- карточки товаров (изображение, название, цена, кнопка «В корзину»);
- фильтр по категории (кнопки-пилюли, поддерживает переход по ссылке
  `/catalog?category=Сайты` из блока категорий на главной);
- сортировка по цене (по умолчанию / сначала дешевле / сначала дороже);
- фильтр и сортировка синхронизированы с URL (`?category=...&sort=...`) —
  состояние каталога можно скопировать ссылкой или обновить страницу без
  потери фильтров.

### Карточка товара (`/product/:id`)

- изображение, название, цена, описание;
- таблица характеристик;
- переключатель количества;
- кнопка «Добавить в корзину» с кратковременной обратной связью
  («Добавлено ✓»).

### Корзина (`/cart`) и оформление заказа (`/checkout`)

Не входят в обязательные 3 страницы ТЗ, но нужны, чтобы «Добавление товара в
корзину» было проверяемо целиком, а не только как клик по кнопке:

- корзина хранит список товаров с количеством, считает сумму, позволяет
  менять количество и удалять позиции;
- состояние корзины сохраняется в `localStorage` — переживает перезагрузку
  страницы;
- `/checkout` — простая демо-форма без реального бэкенда: подтверждение
  очищает корзину и показывает экран благодарности.

## Технические решения

- **Состояние корзины** — React Context + `useReducer`
  (`src/context/CartContext.tsx`), доступ через хук `useCart()`. Один
  источник истины для Header (счётчик), Каталога, Карточки товара и Корзины.
- **Фильтрация и сортировка** — через `useSearchParams`, а не локальный
  `useState`, чтобы состояние каталога было частью URL.
- **Товары** — типизированный массив `Product[]` в
  `src/entities/product/mockProducts.ts` вместо `products.json`, чтобы
  сохранить строгую типизацию (`ProductCategory`, `ProductArtVariant`) без
  дополнительного слоя валидации JSON. Переключить на реальный API или
  fetch из `products.json` — вопрос замены одного модуля.
- **Изображения товаров** — вместо стоковых фото, не подходящих по стилю
  магазину услуг, каждая категория получила свою SVG-иллюстрацию
  (`src/components/product/ProductArt.tsx`) в цветах бренда. Лёгкие,
  чёткие на любом экране, без внешних запросов.
- **Адаптив** — мобильное меню в Header (бургер-переключатель),
  адаптивные grid-раскладки карточек (1 → 2 → 3 колонки), проверено на
  1440 / 768 / 390px.
- **Доступность** — видимые focus-ring на интерактивных элементах,
  `aria-live` на счётчике корзины и обратной связи кнопки «В корзину»,
  `aria-expanded`/`aria-controls` на бургер-меню, уважение
  `prefers-reduced-motion`.

## Структура проекта

```
src/
├── app/                    # Точка сборки приложения
│   ├── App.tsx              # Корневой компонент (CartProvider + роутер)
│   └── router.tsx           # Конфигурация маршрутов
│
├── pages/                  # Страницы (по одной папке на роут)
│   ├── HomePage/
│   ├── CatalogPage/
│   ├── ProductPage/
│   ├── CartPage/
│   ├── CheckoutPage/
│   └── NotFoundPage/
│
├── components/
│   ├── layout/               # Header, Footer, Layout (обёртка с <Outlet />)
│   ├── ui/                   # Переиспользуемые UI-примитивы (Button)
│   ├── product/               # ProductCard, ProductArt, AddToCartButton
│   └── sections/               # Секции главной: Banner, CategoriesBlock, FeaturedProducts
│
├── context/                 # CartContext (React Context + useReducer)
├── hooks/                    # useCart
├── entities/
│   └── product/                # mockProducts.ts — данные о товарах
│
├── types/                    # Product, CartItem и связанные типы
├── lib/                       # Утилиты (форматирование цены)
├── assets/                     # Статика, попадающая в сборку
└── index.css                   # Tailwind + design tokens
```

## Маршруты

| Путь           | Страница           |
| -------------- | ------------------ |
| `/`            | Главная            |
| `/catalog`     | Каталог товаров    |
| `/product/:id` | Карточка товара    |
| `/cart`        | Корзина            |
| `/checkout`    | Оформление заказа  |
| `*`            | 404                |

## Дизайн-токены

Цвета и шрифты заданы через `@theme` в `src/index.css` (Tailwind v4):
`--color-ink`, `--color-paper`, `--color-accent`, `--color-accent-soft`,
`--color-line`, `--font-display`, `--font-body`. Меняйте их там — переменные
подхватятся во всех компонентах.

## Известные ограничения

- Нет бэкенда: товары — статичный массив, `/checkout` ничего никуда не
  отправляет.
- Нет автотестов — проект небольшой, проверка ручная (`npm run build` и
  `npm run lint` проходят чисто).
